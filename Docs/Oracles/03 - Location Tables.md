## Location Tables

Use this file for mission and encounter location prompts.

## Location Scale Oracle

How to use:

Roll `1d6` when location scale is unknown.

| d6  | Scale    |
| :-- | :------- |
| 1-3 | Tactical |
| 4-5 | Grand    |
| 6   | Colossal |

## Site Anomaly Oracle

How to use:

Roll `1d20` when location may have unusual supernatural or environmental condition.

| d20   | Anomaly        |
| :---- | :------------- |
| 1-10  | Normal         |
| 11-12 | Static         |
| 13-14 | Sensory Glitch |
| 15-16 | Hazard         |
| 17-18 | Spatial Loop   |
| 19    | Mana Dense     |
| 20    | Reality Breach |
