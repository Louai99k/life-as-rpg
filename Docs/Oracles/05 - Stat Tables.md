## Stat Tables

Use this file to determine which base stats contribute to `Resolution Score`.

## Event-To-Stat Reference

How to use:

Choose row matching current event. Add only listed stats to `Resolution Score`.

| Event Type             | Contributing Stats      |
| :--------------------- | :---------------------- |
| Melee combat           | Strength + Agility      |
| Ranged combat          | Dexterity + Wisdom      |
| Stealth / infiltration | Agility + Dexterity     |
| Chase / escape         | Agility + Strength      |
| Hacking / tech         | Intelligence + Wisdom   |
| Investigation          | Intelligence + Wisdom   |
| Negotiation / social   | Charisma + Wisdom       |
| Leadership / command   | Charisma + Intelligence |
| Survival / endurance   | Strength + Wisdom       |
| Magic control          | Intelligence + Wisdom   |

## Stat Pair Oracle

How to use:

Roll `1d6` when event does not match `Event-To-Stat Reference` and Game Master does not choose stat pair manually.

| d6  | Stat Pair               |
| :-- | :---------------------- |
| 1   | Strength + Agility      |
| 2   | Agility + Dexterity     |
| 3   | Dexterity + Wisdom      |
| 4   | Intelligence + Wisdom   |
| 5   | Charisma + Wisdom       |
| 6   | Charisma + Intelligence |
