## Narrative Tables

Use this file for narrative prompts that do not directly define core scaling math.

## Fortune Oracle

How to use:

Roll `1d6` when asking a yes/no oracle question.

| d6  | Result                           |
| :-- | :------------------------------- |
| 6   | Yes, and...                      |
| 5   | Yes                              |
| 4   | Yes, but...                      |
| 3   | No, but...                       |
| 2   | No                               |
| 1   | No, and... Roll Major Plot Twist |
