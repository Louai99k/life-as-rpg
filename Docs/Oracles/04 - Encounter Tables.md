## Encounter Tables

Use this file for enemy and encounter prompts.

## Power Source Oracle

How to use:

Roll `1d6` when enemy or power source is unknown.

| d6  | Source |
| :-- | :----- |
| 1-3 | Skill  |
| 4-5 | Magic  |
| 6   | Hybrid |

## Ability Domain Oracle

How to use:

Roll `1d12` when enemy, ability, item, or set needs a domain prompt.

| d12 | Domain     |
| :-- | :--------- |
| 1   | Precision  |
| 2   | Combustion |
| 3   | Fortitude  |
| 4   | Agility    |
| 5   | Stealth    |
| 6   | Toxin      |
| 7   | Force      |
| 8   | Frost      |
| 9   | Voltage    |
| 10  | Psych      |
| 11  | Recovery   |
| 12  | Summon     |

## Requirement Type Oracle

How to use:

Roll `1d12` when mission or encounter needs objective requirement.

| d12  | Requirement Type   |
| :--- | :----------------- |
| 1-2  | Element            |
| 3-4  | Utility Skill      |
| 5-6  | Lore / Intel       |
| 7-8  | Mobility / Stealth |
| 9-10 | Key Item           |
| 11   | Sacrifice          |
| 12   | None               |

## Stakes Oracle

How to use:

Roll `1d6` when encounter failure consequence needs stakes level.

| d6  | Stake                     |
| :-- | :------------------------ |
| 1-2 | Low, time loss            |
| 3-4 | Risky, resource loss      |
| 5   | Dangerous, major penalty  |
| 6   | Deadly, major consequence |

## NERF Penalty Reference

How to use:

Use encounter rank to choose penalty when requirement is not met and encounter applies NERF.

| Rank | Penalty |
| :--- | ------: |
| F    |     -10 |
| E    |     -20 |
| D    |     -50 |
| C    |     -80 |
| B    |    -120 |
| A    |    -200 |
| S    |    -500 |
| SS   |    -750 |
| SSS  |   -1000 |
| Z    |   -1500 |
