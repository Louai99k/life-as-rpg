## Oracle Rules

Use this file for shared oracle procedure. Use category files for actual content tables.

## General Oracle Procedure

How to use:

Use this procedure before rolling any oracle table. Pick the table that answers current play question, roll its listed die once, then apply result through current scene context.

1. Identify table category.
2. Read table-specific `How to use`.
3. Roll listed die once unless table says otherwise.
4. Apply result.
5. Reroll or override impossible result.

## Core Dice Rules

How to use:

Apply these dice rules to every oracle table unless a table gives its own rule.

| Rule                 | Value                                                  |
| :------------------- | :----------------------------------------------------- |
| Roll count           | one roll unless table says otherwise                   |
| Rerolls              | up to `3` free rerolls for each individual roll event  |
| Reroll limit         | after `3` rerolls in that event, no more reroll        |
| New event            | starts a new reroll allowance                           |
| Impossible result    | reroll or override                                     |
| Game Master override | always allowed                                         |

## Random Event Persistence

Every random process is a recorded roll event. Save each generated value, reroll, override, and accepted result before later processing depends on it.

If processing fails after a value was generated, retry the process using the saved value. Do not invoke the random generator again unless the Game Master explicitly requests and records a reroll.
