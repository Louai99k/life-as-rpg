## Purpose

This project defines a solo tabletop RPG system for modern urban fantasy play. Documentation must be complete enough that future rules, tables, tooling, and playtests all derive from one consistent source of truth.

## Core Fantasy

Player lives in real modern world while supernatural system overlays reality. At first this layer is hidden, fragmented, or misunderstood, but over time it becomes more visible and more socially consequential. System grants growth, missions, rewards, and access to powers that begin near human edge and can escalate into extreme anime-style ability.

## What This System Is

- Solo-first tabletop system.
- Urban fantasy and LitRPG structure.
- Real-world baseline with supernatural intrusion.
- Rules-first documentation project.
- Designed for one player acting as both protagonist and resolution engine user.
- Built for later software support, but not dependent on software to make sense.

## What This System Is Not

- Not traditional party-based fantasy dungeon crawler.
- Not pure freeform journaling game with no mechanical structure.
- Not video game simulator with real-time resource tracking.
- Not setting where fantasy fully replaces real-world logic.
- Not ruleset that depends on subjective interpretation for core requirement checks.

## Design Priorities

1. Fast play loop over admin overhead.
2. Objective rules over personal guesswork.
3. Strong internal logic across abilities, enemies, and missions.
4. Clear progression with visible rewards.
5. Limited active complexity with high expressive freedom.
6. Balance that feels challenging without grind wall.
7. Documentation modular enough for future app integration.

## Non-Negotiable Rules

- The game must be exclusively tailored for a solo experience where the user is both the Game Master and the active player.
- The setting is our modern, mundane Earth; supernatural elements must begin as hidden or poorly understood "System" overlay, then remain compatible with growing public recognition rather than permanent secrecy, and must not replace real-world physics.
- While player's journey centers on continuous progression, levels, and measurable character improvement, it will also introduce all sort of events (drama, fun, sad etc.).
- The power system must strictly revolve around the three pillars of physical Skills, supernatural Magic, and acquirable Items.
- All core game rules and scaling must prioritize narrative immersion and a fast gameplay loop over excessive administrative tracking.
- Mechanics and requirement checks must be fundamentally objective and consistent, eliminating subjective guesswork.
- The design must support encounters ranging from grounded, everyday scenarios to extreme supernatural combat without breaking its own internal logic.

## Target Experience

Session should feel quick to start, easy to run, and rewarding to resolve. Player should spend more time making choices and imagining scenes than tracking notes, calculating edge cases, or debating whether abilities count for requirements.

System should support both small grounded scenes and large power fantasy escalation while preserving readable rules language.

## Success Criteria

System succeeds when:

- new session can start with minimal setup
- mission generation takes little time
- requirement checks are objective
- active gear stays manageable
- growth feels measurable and satisfying
- balance does not demand extreme grinding
- docs can be handed to future-you without ambiguity
- later software work can map directly to documentation chapters
