### **d20 Resource Passive Genre**

| **d20** | **Genre**                    | **Description / Focus**                                                     |
| ------- | ---------------------------- | --------------------------------------------------------------------------- |
| **1**   | **Sensory Enhancement**      | Improves sight, hearing, or detection of hidden things/magic.               |
| **2**   | **Physical Resilience**      | Hardening the body against physical damage (impact, cuts).                  |
| **3**   | **Mental Fortitude**         | Resistance to fear, mind control, or stress.                                |
| **4**   | **Environmental Adaptation** | Resistance to heat, cold, radiation, or toxins.                             |
| **5**   | **Social Influence**         | Boosts to persuasion, intimidation, or trustworthiness.                     |
| **6**   | **Economic Efficiency**      | Discounts in shops, better selling prices, or finding more money.           |
| **7**   | **Intuition / Luck**         | Vague "gut feelings" that warn of danger or slightly alter probability.     |
| **8**   | **Recovery / Metabolism**    | Faster natural healing or slower hunger/thirst/energy drain.                |
| **9**   | **Technical Aptitude**       | Passive bonus to using technology, hacking, or repairing items.             |
| **10**  | **Stealth / Obscurity**      | Being harder to notice or remember; blending into crowds.                   |
| **11**  | **Resource Capacity**        | Increases maximum storage for Money, Ki, or Items (inventory space).        |
| **12**  | **Knowledge / Database**     | Instant recall of facts, history, or identifying monster weaknesses.        |
| **13**  | **Precision / Focus**        | Increases accuracy or critical hit chance (finding the weak spot).          |
| **14**  | **Elemental Affinity**       | Passive resistance to or boosting of a specific element (Fire, Ice, etc.).  |
| **15**  | **Mobility / Traversal**     | _Not speed_, but capability: climbing, swimming, or balance.                |
| **16**  | **Aura / Presence**          | An area of effect around you that slightly buffs allies or debuffs enemies. |
| **17**  | **Item Efficiency**          | Consumables last longer or tools don't break as easily.                     |
| **18**  | **Learning / Growth**        | Slight bonus to XP gain or faster skill proficiency leveling.               |
| **19**  | **Retaliation**              | Dealing minor damage or effects back to attackers (Thorns effect).          |
| **20**  | **Identity / Mask**          | Hides your true stats/level from others who try to inspect you.             |

### **d20 Resource Trigger Condition**

| **d20** | **Trigger Context**   | **Example / Description**                                                           |
| ------- | --------------------- | ----------------------------------------------------------------------------------- |
| **1**   | **Elemental Rivalry** | vs. a specific Element (e.g., Water vs. Fire).                                      |
| **2**   | **Health Crisis**     | When your HP is critical (e.g., < 25%).                                             |
| **3**   | **Environment**       | Specific weather or lighting (e.g., In Rain, Under Moonlight).                      |
| **4**   | **Enemy Type**        | vs. specific Enemy Class (e.g., vs. Magic Users, vs. Beasts).                       |
| **5**   | **Momentum**          | If you successfully hit/damaged the enemy last turn.                                |
| **6**   | **Desperation**       | If you took damage or missed your attack last turn.                                 |
| **7**   | **Lucky Number**      | If your Main Power Roll matches a specific number (e.g., ends in 7).                |
| **8**   | **Sacrifice**         | You must pay extra Ki, HP, or Money to activate it.                                 |
| **9**   | **First Blood**       | Activates only during the first round of combat.                                    |
| **10**  | **Executioner**       | If the target's Health is already below 10%.                                        |
| **11**  | **Full Charge**       | Activates only if your Ki is at 100% (Max).                                         |
| **12**  | **Empty Tank**        | Activates only if your Ki is at 0% (Desperation move).                              |
| **13**  | **Isolation**         | If there are no allies (or enemies) within close range.                             |
| **14**  | **Crowd Control**     | If you are outnumbered (3+ enemies nearby).                                         |
| **15**  | **Velocity**          | If you moved a significant distance this turn (Hit & Run).                          |
| **16**  | **Stationary**        | If you haven't moved at all this turn (Sniper/Tank stance).                         |
| **17**  | **Status Prey**       | If the target is suffering a status effect (Stunned, Burning).                      |
| **18**  | **Counter-Attack**    | Activates immediately after you block or dodge an attack.                           |
| **19**  | **Zone Control**      | If you are in a specific Location Scale (e.g., Only works in "Tactical" interiors). |
| **20**  | **The Gambit**        | Roll a d6. On 1, you take damage. On 6, the effect triggers.                        |

### **d6 Resource Activation Check**

| **d6**  | **Reliability** | **Instruction**                                                  |
| ------- | --------------- | ---------------------------------------------------------------- |
| **1-3** | **Guaranteed**  | No roll needed. It always works if the Trigger is met.           |
| **4-5** | **Unstable**    | Roll a **d6**. On **4+**, the bonus applies.                     |
| **6**   | **Volatile**    | Roll a **d20**. On **15+**, the bonus applies (usually massive). |
