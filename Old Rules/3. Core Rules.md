# 3. Core Rules

## **1. Conflict Resolution**

When you fight, hack, or negotiate, use this formula to see if you win.

### **The Power Formula**

> **Total Power = Base Stat + Ability Bonus + Luck Die**

- **Base Stat:** Your `Level / 10` (e.g., Level 50 = 5).
- **Ability Bonus:** The power of the Skill, Magic, or Item you are using.
- **Luck Die:** A variable dice roll added based on the _Situation_.

### **The Luck Die (Context)**

Add **one** of these dice to your total.

| Situation      | Die       | Description                         |
| :------------- | :-------- | :---------------------------------- |
| **Routine**    | **+0**    | Safe analysis, no pressure.         |
| **Low Risk**   | **+d6**   | Minor consequence for failure.      |
| **Standard**   | **+d12**  | Normal combat or tricky tasks.      |
| **Deadly**     | **+d20**  | Boss fights, life-or-death moments. |
| **Impossible** | **+d100** | Divine intervention required.       |

> **Success:** If Your Total Power > Enemy Power/Target Number, you succeed.

## **2. Enemy Rules**

Enemies follow **Symmetry**. They work exactly like you.

### **The Symmetry Rule**

- If an enemy is **Level 100**, they have:
  - **Max Ki:** Same formula as you.
  - **Slots:** `3 + (100/10) = 13` Slots.
  - **Stats:** They use the same Power Formula.

### **Quick Build (The "Budget" System)**

Don't build full sheets for enemies. Just use the **Budget**.

- **Total Level Budget:** `Enemy Level * (1d10 + 3)`
- _Example:_ A Level 100 Enemy with a roll of 5 has **500 Levels** to distribute.
  - They might have 5 Skills at Level 100 each.
  - Or 1 Ultimate Magic at Level 500.

### **Enemy Level Determination**

- **Enemy Level** = `Rank Base Level + Dice Roll`
- The dice roll is a random value, but an enemy's level **cannot exceed the next rank's base level**.
- _Example:_ A Rank E enemy (Base Level 50) rolls additional levels, but can never reach **150** (Rank D's Base Level).
- Rank S enemies are capped at the **Level Cap (1000)**.

## **3. The Nerf System (Weaknesses)**

Some enemies or locks are resistant to brute force.

- If a target has a **Nerf**, you subtract a penalty from your Power.
- **To Bypass:** You must meet a specific condition (e.g., "Must use Fire Magic" or "Must use Hacking Skill").
- _See [[5. Oracle Reference|Oracle Reference]] for the Nerf Table._
