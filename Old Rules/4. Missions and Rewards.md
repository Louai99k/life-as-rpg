Use this guide to generate content and get paid.

## **Phase 1: Mission Generation**

Roll on the tables in **[[5. Oracle Reference|Oracle Reference]]** in this order:

1.  **Objective:** What are you doing? (Kill, Steal, Defend...)
2.  **Location:** Where is it? (Scale + Specific Place)
3.  **The Enemy:** Who is stopping you? (Power Source + Rank)
4.  **Stakes:** What happens if you fail?

---

## **Phase 2: The Reward System**

Rewards are based on **Mission Rank** (F to S).
Each Rank gives you a number of **Reward Units**. you can mix and match these units to create a custom reward bundle.

### **Step 1: Determine Budget**

| Mission Rank | Reward Units | XP Award   |
| :----------- | :----------- | :--------- |
| **F**        | 1 Unit       | 50 XP      |
| **E**        | 2 Units      | 250 XP     |
| **D**        | 3 Units      | 1,000 XP   |
| **C**        | 4 Units      | 5,000 XP   |
| **B**        | 5 Units      | 25,000 XP  |
| **A**        | 7 Units      | 100,000 XP |
| **S**        | 10 Units     | 250,000 XP |

### **Step 2: Spend Units**

Combine any of the following options up to your Unit Limit.

| Reward Type      | Cost        | Effect                                                 |
| :--------------- | :---------- | :----------------------------------------------------- |
| **Cash Bundle**  | **1 Unit**  | Gain **$500** (Adjust for economy).                    |
| **Level Points** | **1 Unit**  | Gain **+10 LP** (for upgrading skills).                |
| **Consumable**   | **1 Unit**  | A one-time use item (Potion, Grenade).                 |
| **Equipment**    | **2 Units** | A permanent item (Weapon, Armor). Roll Item Rank.      |
| **New Skill**    | **3 Units** | Learn a new Physical/Tech Skill (Rank F).              |
| **New Magic**    | **3 Units** | Learn a new Magic Spell (Rank F).                      |

### **Examples of "Mixed Rewards"**

- **The Mercenary Payout (Rank D - 3 Units):**
  - 3x Cash Bundles ($1,500).
- **The Wizard's Stash (Rank D - 3 Units):**
  - 1x New Magic (3 Units).
- ** The Raider's Loot (Rank C - 4 Units):**
  - 1x Equipment (2 Units)
  - 1x Cash Bundle (1 Unit)
  - 1x Consumable (1 Unit)

## Altar

- You will be able to request mission from the game if you need to get more powerful and then the game will send you to place called the **Altar**. Its actually located in another dimension and can take any shape depending on the mission. You have 3 mission request each day and at the end of the day, the unfinished missions will be vanished and requests will be reset to 3.
- The altar mission ranks will scale with your current level. Look at [[5. Oracle Reference#5. Oracle Reference#**d7 Rank & Base Level**]].
- No consequences for failure applies for 99% of the altar missions.
